# Blinding and Treatment-Code Manager

Blinding and Treatment-Code Manager

## Slots

- `trial_id`:

  Trial identifier.

- `arms`:

  Ordered arm labels.

- `code_map`:

  Named arm-to-code mapping.

- `kit_codes`:

  Concealed participant-level kit assignments.

- `unblinding_log`:

  Append-only unblinding log.

- `fingerprint`:

  Deterministic semantic-content hash.
