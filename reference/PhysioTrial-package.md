# PhysioTrial: Auditable Clinical-Trial Design and Analysis Workflows

PhysioTrial provides trial data models, concealed allocation sequences,
treatment-code management, CONSORT/SPIRIT operations, adverse-event
summaries, explicit analysis populations, endpoint-analysis helpers, and
auditable CDISC SDTM-shaped and ADaM-shaped exports.
