# Randomized Trial Definition

Randomized Trial Definition

## Slots

- `id`:

  Trial identifier.

- `arms`:

  Ordered arm labels.

- `arm_specs`:

  Arm definitions.

- `allocation_ratio`:

  Named integer allocation weights.

- `strata`:

  Named list of prognostic factors and admissible levels.

- `endpoints`:

  Endpoint definitions carried by the trial.

- `metadata`:

  Free-form trial metadata.
