# Power of a two-arm binary endpoint at a given sample size

Power of a two-arm binary endpoint at a given sample size

## Usage

``` r
powerBinary(n1, p1, p2, sig_level = 0.05, ratio = 1, sides = 2L)
```

## Arguments

- n1:

  Control-arm sample size.

- p1, p2, sig_level, ratio, sides:

  As in
  [`sampleSizeBinary()`](https://x-biosignal.github.io/PhysioTrial/reference/sampleSizeBinary.md).

## Value

The achieved power.
